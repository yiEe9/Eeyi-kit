# 安全与合规

这套东西驱动真实微信账号，读真实聊天记录，能主动发消息、点赞、评论、通过好友、代发。所有能力默认开启，风险由使用者承担。

## 所有能力默认开启

| 能力 | 暴露面 |
|---|---|
| 跨会话人物档案 | 其他人的近况/记忆进入模型请求 |
| 记忆链 | 记忆条目之间建边，写记忆多一次模型调用 |
| 朋友圈 | 读取动态；可能公开点赞/评论 |
| 好友申请 | 可能通过不认识的人 |
| 代发 | 以你的账号给第三人发消息 |
| 记忆镜像 | 设置 `WX_MIRROR` 后，记忆复制到指定位置 |

这些能力也会额外调用模型或写本地文件：长期记忆、口吻库、主动聊天、表情库、群聊点名、循环锁、弹窗守卫、AT-SPI/OCR、发送回读。主动聊天和表情库也会调用模型，但不会公开互动。

## 聊天记录、记忆与 Key 是明文

- `$WX_HOME/config.json`：含 API Key，权限 600。
- `$WX_HOME/history/`：每个会话最近若干条原文。
- `$WX_HOME/memory/`：长期记忆，包含别人的私事。
- `$WX_HOME/inner.log`、`bot_log.md`：模型心想与回复。
- `$WX_HOME/style/`：主人手动打的话。
- `$WX_HOME/atspi_shadow.jsonl`：AT-SPI/OCR 对照，含聊天文本。

没有加密。备份、分享、把机器借人之前，先清 `$WX_HOME`。`.gitignore` 排除了 `kit.env`、`*.config.json`、`persona/*.txt`、`logs/`，但运行时数据通常不在仓库里，仍然要自己管。

## 账号风险

- 微信没有开放这套用法；界面自动化属于非官方客户端行为，可能触发风控、踢下线、限制登录，甚至封号。
- **不要用主号做实验**。用小号，先跑只读自检（`wx-check`）再开 `--send`。
- 不要高频群发、批量加人、刷朋友圈；代码里的限额只是降低风险，不是免死金牌。
- 微信改版后坐标/无障碍树/OCR 规则可能失效；失效时不要用「多点几次」绕过，先停下来重新标定。

## VNC 与虚拟屏

- x11vnc 无密码，只监听 `127.0.0.1:5900`。不要把 5900 转发到公网或 0.0.0.0。
- 远程看屏用 SSH 隧道：`ssh -L 5900:127.0.0.1:5900 用户@机器`。
- Xvfb 里是完整微信窗口，任何能连上 VNC 的人都能操作你的账号。

## 模型与第三方

- 聊天文本、图片裁图、记忆摘要会发给你配置的 `base_url`。选可信的服务商，别把 Key 填进来源不明的中转。
- 视觉兜底会把聊天区截图发给模型；朋友圈、表情识别同理。
- 跨会话档案会把其他人的档案一起发出去；如果不想暴露，不要把敏感联系人放进 `contacts.json`，或自行修改代码。

## 人格与冒充

- 仓库不带人格；`persona/persona.txt` 由使用者自己写。
- 「不是 AI」是角色扮演，不是诈骗许可。不要用它冒充真人骗钱、骗感情、批量骚扰、伪造身份或做违法的事。
- 如果公开部署给别人用，需要明确告知对方这是自动回复，并遵守当地法律与平台规则。

## 删除与撤回

- 停服务：`bash phone/start.sh stop` / `bash pc/start.sh stop`。
- 删某个人的数据：见 [operations.md](operations.md) 的「让某人失忆」。
- 删全部运行时数据：停服务后删除 `$WX_HOME`（先备份需要的部分）。这是不可逆操作，确认后再做。
