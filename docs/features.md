# 能力清单

所有能力默认开启，没有能力开关；`config` 只问人格、模型与行为参数。下面每项按自己的触发条件自动执行，不需要逐项打开。

唯一的运行期条件是记忆镜像：设置了 `WX_MIRROR` 才会复制记忆目录，未设置时什么都不做。

电脑版命令里的 `$PREFIX` 默认是 `$HOME/.local/share/phone-ai`；没设置时先 `PREFIX=${PREFIX:-$HOME/.local/share/phone-ai}`。

---

## 1. 跨会话人物档案与跨人联动

- **做什么**：生成上下文时注入通讯录里其他人的一行摘要；对方提到某人时，展开那人的近况和相关记忆。模型在主人会话里可以用 `[[发送:名字|内容]]` 让系统代发。
- **什么时候触发**：每次生成回复时；只有对方提到通讯录里的人才展开细节。
- **代价**：上下文更长、token 更多；别人的私事会进入模型请求。群聊里会按发言人分别读取各自的一对一历史和记忆。

## 2. 长期记忆库

- **做什么**：每人一份 `$WX_HOME/memory/<名字>/MEMORY.md`，模型用 `<记住>...</记住>` 写入；生成时按内容挑相关条目注入。整个记忆目录会做成 git 仓库，写入后自动提交。
- **什么时候触发**：每轮生成都读；模型输出 `<记住>` 时写。
- **代价**：每条记忆会进入上下文；git 会保留历史，删了也能从 git 找回。自动提交需要系统已安装 `git`，否则跳过提交（记忆本身照常写入）。

## 3. 记忆链

- **做什么**：记忆条目之间建立边。写入时用模型判断语义相关（`mem_link`），同时按字面相似度建边；生成时从关键词命中的条目沿边扩散，把相关的事一起想起来。
- **什么时候触发**：写记忆、生成回复时。
- **代价**：写记忆多一次模型调用；`graph.json` 会变大。维护命令：`--mem-relink 名字`、`--mem-graph 名字`、`--mem-rebuild 名字`。

## 4. 口吻库

- **做什么**：从可见聊天记录里识别「主人手动用这个号打出、不是 bot 发的」句子，存到 `$WX_HOME/style/<名字>.txt`；生成时取最近 12 行作参考。
- **什么时候触发**：每轮读消息时；只学长度 ≥3、非占位符、与已发送记录对不上的句子。
- **代价**：会把你亲手打的话写进本地文件；不会整段照抄，只作语气参考。

## 5. 主动聊天

- **做什么**：按六个时间段（早/午/下午/晚/晚安/深夜）抽签，挑一个联系人主动发一句话；有每日总量、同一人次数和最小间隔限制。
- **什么时候触发**：聊天安静超过 8 分钟、距上次评估 150 秒、时段未用过、抽签通过。
- **代价**：额外模型调用；可能打扰别人。状态写在 `$WX_HOME/proactive.json`（dry-run 写 `proactive.dry.json`）。

## 6. 久未回追问

- **做什么**：bot 自己最后一句发出去超过 4 小时、对方一直没回、主人也没手动用这个号回过，就在 7:00–23:00 之间轻轻问一句。
- **什么时候触发**：每轮主动评估时；同一条消息只问一次，跨天也保留去重键。
- **代价**：一次模型调用；问多了会烦人，代码里限制了每日次数和最小间隔。

## 7. 朋友圈

- **做什么**：扫朋友圈动态记进对应人的记忆；`--send` 模式下按模型判断点赞、评论；有新评论/回复时读通知区并回复。
- **什么时候触发**：主循环空闲 30 分钟且有 50% 概率；或手动运行 `--moments`、`--moments-reply`。
- **代价**：视觉模型调用多、耗时；点赞和评论是公开动作，可能被对方看到。话题私密时模型应选择不互动，但不能保证。

## 8. 好友申请

- **做什么**：侧栏通讯录红点亮时，自动点「新的朋友」→「前往验证」→ 通过；可填备注，并把新好友加进 `contacts.json`。开场白来自 `wechat_opener` / `wechat_opener_late`，没配就不主动说话。
- **什么时候触发**：每 120 秒检查一次红点；主人会话里说「通过好友申请」也会触发。
- **代价**：可能通过不认识的人；会点真实界面，弹窗异常时可能误点（有危险弹窗守卫兜底）。

## 9. 表情库

- **做什么**：识别对方发来的贴纸，模型判断是否收藏；收藏到微信原生表情和 `$WX_HOME/stickers/`；回复后按情绪决定是否补一个表情包。
- **什么时候触发**：收到图片/表情消息时；每次发送文字回复后；启动时如果表情目录为空会建一次。
- **代价**：视觉模型调用；打开表情面板会短暂占用界面。可选本地语义模型 `WX_EMB_DIR`（默认程序目录下 `models/bge-small-zh`）缺失时自动退回全清单。

## 10. 代发

- **做什么**：主人在聊天里写 `[[发送:名字|内容]]`，bot 切到那个人的会话把内容发出去，并回读确认。
- **什么时候触发**：只在 `contacts.json` 里 role=owner 的会话；模型被注入代发规则后才会产出该格式。
- **代价**：以你的账号给第三人发消息，发错人风险由使用者的联系人名单和代码的会话名校验共同承担。

## 11. 群聊点名

- **做什么**：群聊里只有消息包含 `CFG.name` 或 `@名字最后一个字` 时才回复；被点名时向上翻一屏补上下文。
- **什么时候触发**：每轮处理群消息时。`name` 为空时该功能自动失效，不会误触发。
- **代价**：群里没人叫它时不会回，模型调用较少；被点名时会多读一屏上下文。

## 12. 记忆镜像（需要 `WX_MIRROR`）

- **做什么**：把 `$WX_HOME/memory/`（不含 `.git`）复制到 `WX_MIRROR` 指定目录，方便放到同步盘或别的备份位置。
- **什么时候触发**：启动时一次；运行中记忆有改动后 120 秒内补一次。没设置 `WX_MIRROR` 时直接返回，不创建目录、不复制。
- **代价**：把记忆（包含别人的私事）复制到另一个位置；目标目录的权限和同步范围由你自己负责。

## 13. 话题循环锁

- **做什么**：自己最近 6 条里 ≥4 条出现同一个词，或对方明确说「别再说了」，锁 3 轮，期间提示模型换话题。
- **什么时候触发**：每次生成回复前。锁状态在 `$WX_HOME/state.json` 的 `loop` 字段。
- **代价**：只读已有上下文 + 本地分词，不额外调模型；可能偶尔误锁。

## 14. 危险弹窗守卫

- **做什么**：屏幕上出现「退出登录」「解锁以继续」时停止操作；退出登录确认框点「取消」，其它危险弹窗按 Esc 并跳过本轮。截图存 `$WX_HOME/danger.png`。
- **什么时候触发**：每轮读屏、朋友圈操作、主动发送前。
- **代价**：极少数情况下会把正常文字里的「退出登录」当成弹窗，跳过一轮。

## 15. AT-SPI 读消息

- **做什么**：通过微信 Qt 暴露的无障碍树读会话名、消息文本、输入框和状态标志；文本比 OCR 精确，方位仍用截图几何校验。
- **什么时候触发**：每轮读消息；初始化失败自动回退 OCR。
- **代价**：首次 warm 约 2–4 秒，之后每轮几十毫秒；无障碍树改版可能失效，代码有回退。需要 `python3-gi` 与 `gir1.2-atspi-2.0`，安装脚本已带。

## 16. OCR 兜底

- **做什么**：RapidOCR 对 Xvfb 截图逐字识别；AT-SPI 不可用或结果不确定时用它。图片/贴纸区域先排除文字，再交给视觉模型补描述。
- **什么时候触发**：每轮读屏。
- **代价**：CPU 占用；模型下载约几百 MB。视觉兜底会额外调用模型。

## 17. 发送回读校验

- **做什么**：发送后重新截图，确认聊天区最后几条里真的有这句话；没有就标记未确认，避免「以为发了其实没发」。
- **什么时候触发**：每次发送文字后。
- **代价**：多一次截图 + OCR，约 0.6 秒。

## 配置里的其它键

| 键 | 作用 |
|---|---|
| `name` | 对外自称；群聊点名、上下文标题、日志用 |
| `owner_call` | 怎么称呼主人，默认「你」；代发规则和「心想是不是草稿」判断用 |
| `system_prompt` | 人格正文，来自 `persona/persona.txt` |
| `owner_prompt` / `other_prompt` | 对主人 / 其他人的追加设定 |
| `base_url` / `model` / `api_key` | OpenAI 兼容接口 |
| `utc_offset` | 时区偏移（小时），兼容旧配置 |
| `history_limit` | 每个会话保留的历史条数，默认 30 |
| `reply_limit` | 单条回复最大字数，默认 400 |
| `min_interval` | 兼容旧配置的最小回复间隔，微信通道不强制使用 |
| `humanize` | 兼容旧配置；微信通道的像人逻辑常开 |
| `wechat_opener` | 新好友开场白列表，留空则不主动开口 |
| `wechat_opener_late` | 加了很久没说话时的开场白，留空用 `wechat_opener` |

旧配置里的 `features` 和顶层 `proactive` 已不再读取，保留也不影响启动。
